# PrintStuff

Custom B2B apparel ordering platform.

## Current
- Customer storefront
- Product catalogue from supplied PrintStuff PDF
- Bulk pricing
- Product customizer
- Artwork upload UI
- Cart counter
- Order tracking UI
- Admin portal entry point

## Next production layer
- PostgreSQL persistence
- Admin authentication
- Real orders and customers
- Artwork storage
- Payment integration
- WhatsApp/email notifications
- Full order status history

Catalogue source: supplied 7-page PrintStuff B2B catalogue. Shipping is extra on all orders; apparel sizes S/M/L/XL/XXL; cap is universal free size.
